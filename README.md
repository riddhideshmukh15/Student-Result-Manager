# 🎓 Student Result Manager

## 📌 About the Project

Student Result Manager is a beginner-friendly Python project that takes a student's name and marks in different subjects. It calculates the total marks, percentage, grade, and final pass/fail result.

## ✨ Features

* Enter student's name
* Enter marks for different subjects
* Calculate total marks
* Calculate percentage
* Assign grade based on percentage
* Display PASS or FAIL result
* Display a simple result report

## 🛠️ Technologies Used

* Python 3

## 📚 Subjects

The project currently includes:

* Maths
* Physics
* Chemistry
* English
* Python

## 📊 Grading System

| Percentage    | Grade |
| ------------- | ----- |
| 90% and above | A+    |
| 80% – 89%     | A     |
| 70% – 79%     | B     |
| 60% – 69%     | C     |
| 50% – 59%     | D     |
| Below 50%     | F     |

## ▶️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd Student-Result-Manager
```

3. Run the Python file:

```bash
python student_result_manager.py
```
